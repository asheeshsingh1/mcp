## MCP Servers

We are going to connect with 2 servers running locally and 2 servers running on remotely.

Local:

* One with built in connector feature from anthropic, eg: Filesystem(Access Files Locally)
* One with editing config of claude desktop locally, eg: Manim MCP Server(For Animations)

Remote:

* One with built in connector feature from anthropic, eg: Google Drive(Read Only)
* One with editing config of claude desktop locally, eg: Weather MCP Server(Get Weather)
